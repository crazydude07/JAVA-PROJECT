The Student Grade Management System is a Java-based application developed to simplify the process of evaluating and managing a student’s academic performance. The program accepts important student details such as the student’s name, number of subjects, marks obtained in each subject, and attendance percentage. It then calculates the total marks and average marks and assigns an appropriate grade based on predefined performance criteria.

The system also checks whether the student has achieved the minimum required attendance of 75% and displays their examination eligibility. To make the program reliable, input validation is included to ensure that the number of subjects is positive and that marks entered are within the valid range of 0 to 100. The program demonstrates the practical implementation of important Java programming concepts such as Scanner for input, variables, arithmetic operations, if-else statements, else-if ladder, for loops, and while loops.

Overall, this project provides a simple and efficient way to evaluate student performance while demonstrating how basic programming concepts can be combined to create a useful real-world application. It can also serve as a foundation for developing more advanced student management systems with features such as storing multiple student records, calculating rankings, and generating detailed reports.
